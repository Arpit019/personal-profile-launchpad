# Competitive Analysis

Analyze competitors on substance — what they actually do, not what they claim.

## When to Activate
- Entering a new market or category
- Positioning a product against incumbents
- Pricing strategy decisions
- Feature prioritization based on market gaps
- Investor materials requiring market context

## Analysis Framework

### Step 1: Identify Competitors
- **Direct**: Solve the same problem for the same user
- **Indirect**: Solve the same problem differently
- **Substitute**: Users might choose instead of solving the problem
- **Potential**: Could enter this space easily

### Step 2: Feature Matrix
Compare on actual capabilities, not marketing claims.
Test the product yourself or use credible reviews.

### Step 3: Positioning Analysis
Map competitors on 2 meaningful axes relevant to user decisions.

### Step 4: SWOT per Competitor
Based on evidence (user reviews, product usage, public data), not speculation.

### Step 5: Strategic Recommendation
- **Where to compete**: Features/segments where we can win
- **Where NOT to compete**: Battles we'd lose
- **Differentiation opportunity**: Unserved needs in the market

## Quality Gate
- Feature comparisons are verified, not assumed
- Pricing data is current (within 3 months)
- User sentiment is from actual reviews, not press releases
- Recommendation is actionable and specific
